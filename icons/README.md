# Icon Files

You need to add three icon files to this directory:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

## How to create icons:

1. Create or download a KEXP logo image
2. Resize it to the three sizes above
3. Save them as PNG files in this directory

You can use online tools like:
- https://www.photopea.com/ (free online Photoshop alternative)
- https://www.canva.com/ (easy design tool)
- Or any image editing software you have

For a quick placeholder, you can create simple red square icons with "KEXP" text.
