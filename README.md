# KEXP Now Playing Chrome Extension

A Chrome extension that displays what's currently playing on KEXP.org radio stream.

## Features

- Shows currently playing track information including:
  - Track name
  - Artist name (with local artist indicator)
  - Album name
  - Album artwork
  - Record label
  - Play time
  - DJ comments (when available)
- Clean, dark-themed interface matching KEXP branding

## Usage

Click the KEXP extension icon in your Chrome toolbar to see what's currently playing on KEXP.org.


## API

This extension uses the KEXP API: https://api.kexp.org/v1/

## Files

- `manifest.json` - Extension configuration
- `popup.html` - Popup interface structure
- `popup.css` - Styling
- `popup.js` - JavaScript to fetch and display track data
- `icons/` - Extension icons (you need to add these)
